# 分类与数据规范更新｜2026-07-25

## 1. 新增数据类型

### `generated_tactile`

由RGB、机器人状态或其他模态推断的触觉数据。必须与真实传感器输出严格分离，不得写入`raw_tactile`字段。

必需字段：

- `tactile_source = generated`
- `generator_model`
- `generator_checkpoint`
- `generator_version`
- `source_rgb_frame_id`
- `source_state_frame_id`
- `generation_timestamp`
- `generation_confidence`
- `target_sensor_model`
- `target_taxel_layout`
- `latency_correction`

### `controller_conditioned_action`

策略不仅预测运动，还预测低层控制器行为的动作表示。

建议字段：

- `virtual_target_pose`
- `stiffness_matrix`
- `damping_matrix`
- `impedance_admittance_ratio`
- `controller_mode`
- `force_target`
- `force_growth_rate`
- `low_level_torque_command`
- `controller_version`

### `refined_demonstration`

经过停顿删除、平滑、重采样、成功验证或数据增强的示教。必须保留原始轨迹父级。

建议字段：

- `raw_trajectory_id`
- `refined_trajectory_id`
- `refinement_pipeline_version`
- `hesitation_removed`
- `smoothing_method`
- `resample_rate_hz`
- `validation_result`
- `augmentation_manifest`
- `parent_data_hash`

### `instruction_factor_profile`

用于按模型薄弱因素分配数据采集预算。

建议因素：

- `color`
- `object_identity`
- `spatial_relation`
- `verb_or_skill`
- `size`
- `material`
- `contact_type`
- `required_force_level`
- `bimanual_role`

配套字段：

- `factor_coverage_count`
- `factor_success_rate`
- `factor_mastery_score`
- `collection_priority`
- `demonstration_budget`
- `marginal_gain_per_demo`

### `sim_real_interface_parity`

用于描述数字孪生与真机控制、状态和数据接口是否同构。

必需字段：

- `simulator_name`
- `sim_asset_version`
- `real_hardware_sku`
- `transport_sim`
- `transport_real`
- `topic_map`
- `message_schema_hash_sim`
- `message_schema_hash_real`
- `joint_order_hash_sim`
- `joint_order_hash_real`
- `unit_convention`
- `control_mode_parity`
- `camera_frame_parity`
- `missing_physics_channels`
- `sim_real_switch_config`

`missing_physics_channels`必须显式列出电流、力矩、摩擦、腱耦合、tip contact、触觉或高层控制接口等缺失内容。不得用零值冒充不存在的真实信号。

### `experience_refinement_round`

用于记录真机自主rollout、人工纠错和再次后训练之间的关系。

建议字段：

- `refinement_round`
- `policy_checkpoint_parent`
- `policy_checkpoint_child`
- `teleop_episode_ids`
- `autonomous_rollout_ids`
- `human_correction_ids`
- `success_count`
- `failure_count`
- `advantage_label`
- `value_score`
- `ood_score`
- `data_mix_ratio`
- `curation_pipeline_version`
- `evaluation_set_hash`
- `performance_before`
- `performance_after`
- `rollback_required`

## 2. 新增多阶段双臂操作schema

所有handover/regrasp类episode建议分为：

- `pick`
- `transfer`
- `handover_approach`
- `dual_contact`
- `release_source_hand`
- `regrasp`
- `place_or_use`

每阶段保存：

- `stage_id`
- `active_arm`
- `support_arm`
- `left_eef_pose`
- `right_eef_pose`
- `left_hand_state`
- `right_hand_state`
- `object_pose`
- `grasp_candidate_id`
- `collision_score`
- `reachability_score`
- `stability_score`
- `stage_transition_success`
- `regrasp_reason`

## 3. 真实触觉与生成触觉的层级

### 原始真实层

- `raw_taxel`
- `raw_tactile_image`
- `raw_wrench`
- `sensor_device_timestamp`
- `calibration_state`

### 对齐真实层

- `aligned_tactile`
- `alignment_method`
- `measured_latency`
- `interpolation_method`
- `source_frame_ids`

### 生成层

- `generated_tactile`
- `generator_checkpoint`
- `generation_confidence`
- `target_sensor_layout`

### 派生层

- `contact_state`
- `normal_force`
- `shear_force`
- `slip_score`
- `tactile_latent`

原则：任何生成、插值或派生数据都不得覆盖原始传感器流。

## 4. 数据许可注册表

AXIS等受控数据集表明，开放链接不等于允许再分发。所有外部数据必须记录：

- `dataset_name`
- `dataset_version`
- `source_url`
- `access_type = open/controlled/commercial`
- `license_name`
- `commercial_use_allowed`
- `redistribution_allowed`
- `derivative_model_allowed`
- `public_mirror_allowed`
- `access_request_date`
- `download_date`
- `terms_snapshot_hash`

公共仓库只能保存许可允许公开的元数据、链接和自有分析。

## 5. 新增频率与时间轴字段

真实VLA部署必须区分：

- `sensor_native_rate_hz`
- `camera_rate_hz`
- `record_rate_hz`
- `control_rate_hz`
- `policy_rate_hz`
- `state_publish_rate_hz`
- `timestamp_source`
- `clock_domain`
- `resample_method`
- `dropped_frame_count`
- `command_execution_latency`

原则：不得仅写“数据30Hz”而不说明相机、状态、动作、落盘和推理分别以何种频率运行。

## 6. 新增掌部结构与动作抽象层级

### 掌部字段

- `palm_dof`
- `palm_active_dof`
- `palm_passive_dof`
- `palm_articulation_type`
- `palm_configuration`
- `palm_state`
- `palm_asset_version`

### 动作抽象层级

- `full_joint_action`
- `synergy_action`
- `binary_open_close`
- `semantic_grasp_action`
- `eef_only_action`

例如DEED将Dex-3简化为二值开/闭动作，因此只能标记为`binary_open_close`，不能与完整多指关节数据混合统计。

## 7. 数据回流质量门控

自动经验数据进入训练集前至少检查：

1. 是否与固定评测集分离；
2. 是否存在大量重复、停滞或失败尾段；
3. OOD分数是否超过阈值；
4. 自主数据与人类数据比例是否受控；
5. 每轮checkpoint与数据快照是否可回滚；
6. 性能下降时能否定位具体新增episode和处理步骤。

## 8. 新增评价维度

- **触觉补全价值：** 生成触觉相对vision-only的任务增益、与真实触觉的性能差距。
- **控制器可复现性：** 是否保存虚拟目标、刚度、阻尼、控制器模式和低层命令。
- **轨迹精炼可追溯性：** raw/refined是否一一绑定，处理步骤是否可重放。
- **因素覆盖效率：** 每条新增示教对薄弱因素的边际收益。
- **多阶段双臂完整性：** handover双接触区间、释放顺序和重抓原因是否可恢复。
- **许可合规性：** 数据能否下载、训练、再分发、公开镜像和商业使用。
- **sim-real接口同构度：** topic、消息、关节顺序、单位、控制模式和相机坐标是否一致。
- **缺失物理通道透明度：** 仿真中缺少的电流、力矩、触觉和接触是否明确标记。
- **经验回流稳定性：** 连续refinement轮次是否持续提升，能否识别分布漂移和性能退化。
- **掌部结构价值：** articulated palm相对flat palm在任务成功率、可达空间和策略效率上的增益。
