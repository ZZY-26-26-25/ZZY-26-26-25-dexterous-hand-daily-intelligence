# 分类与数据规范更新｜2026-07-25

## 1. 新增数据类型

### `generated_tactile`

由RGB、机器人状态或其他模态推断的触觉数据。必须与真实传感器输出严格分离，不得写入`raw_tactile`字段。

必需字段：

- `tactile_source = generated`
- `generator_model`
- `generator_checkpoint`
- `generator_version`
- `source_rgb_frame_id`
- `source_state_frame_id`
- `generation_timestamp`
- `generation_confidence`
- `target_sensor_model`
- `target_taxel_layout`
- `latency_correction`

### `controller_conditioned_action`

策略不仅预测运动，还预测低层控制器行为的动作表示。

建议字段：

- `virtual_target_pose`
- `stiffness_matrix`
- `damping_matrix`
- `impedance_admittance_ratio`
- `controller_mode`
- `force_target`
- `force_growth_rate`
- `low_level_torque_command`
- `controller_version`

### `refined_demonstration`

经过停顿删除、平滑、重采样、成功验证或数据增强的示教。必须保留原始轨迹父级。

建议字段：

- `raw_trajectory_id`
- `refined_trajectory_id`
- `refinement_pipeline_version`
- `hesitation_removed`
- `smoothing_method`
- `resample_rate_hz`
- `validation_result`
- `augmentation_manifest`
- `parent_data_hash`

### `instruction_factor_profile`

用于按模型薄弱因素分配数据采集预算。

建议因素：

- `color`
- `object_identity`
- `spatial_relation`
- `verb_or_skill`
- `size`
- `material`
- `contact_type`
- `required_force_level`
- `bimanual_role`

配套字段：

- `factor_coverage_count`
- `factor_success_rate`
- `factor_mastery_score`
- `collection_priority`
- `demonstration_budget`
- `marginal_gain_per_demo`

## 2. 新增多阶段双臂操作schema

所有handover/regrasp类episode建议分为：

- `pick`
- `transfer`
- `handover_approach`
- `dual_contact`
- `release_source_hand`
- `regrasp`
- `place_or_use`

每阶段保存：

- `stage_id`
- `active_arm`
- `support_arm`
- `left_eef_pose`
- `right_eef_pose`
- `left_hand_state`
- `right_hand_state`
- `object_pose`
- `grasp_candidate_id`
- `collision_score`
- `reachability_score`
- `stability_score`
- `stage_transition_success`
- `regrasp_reason`

## 3. 真实触觉与生成触觉的层级

### 原始真实层

- `raw_taxel`
- `raw_tactile_image`
- `raw_wrench`
- `sensor_device_timestamp`
- `calibration_state`

### 对齐真实层

- `aligned_tactile`
- `alignment_method`
- `measured_latency`
- `interpolation_method`
- `source_frame_ids`

### 生成层

- `generated_tactile`
- `generator_checkpoint`
- `generation_confidence`
- `target_sensor_layout`

### 派生层

- `contact_state`
- `normal_force`
- `shear_force`
- `slip_score`
- `tactile_latent`

原则：任何生成、插值或派生数据都不得覆盖原始传感器流。

## 4. 数据许可注册表

AXIS等受控数据集表明，开放链接不等于允许再分发。所有外部数据必须记录：

- `dataset_name`
- `dataset_version`
- `source_url`
- `access_type = open/controlled/commercial`
- `license_name`
- `commercial_use_allowed`
- `redistribution_allowed`
- `derivative_model_allowed`
- `public_mirror_allowed`
- `access_request_date`
- `download_date`
- `terms_snapshot_hash`

公共仓库只能保存许可允许公开的元数据、链接和自有分析。

## 5. 新增评价维度

- **触觉补全价值：** 生成触觉相对vision-only的任务增益、与真实触觉的性能差距。
- **控制器可复现性：** 是否保存虚拟目标、刚度、阻尼、控制器模式和低层命令。
- **轨迹精炼可追溯性：** raw/refined是否一一绑定，处理步骤是否可重放。
- **因素覆盖效率：** 每条新增示教对薄弱因素的边际收益。
- **多阶段双臂完整性：** handover双接触区间、释放顺序和重抓原因是否可恢复。
- **许可合规性：** 数据能否下载、训练、再分发、公开镜像和商业使用。
