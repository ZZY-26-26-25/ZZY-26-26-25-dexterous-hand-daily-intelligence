# 分类与数据规范更新｜2026-07-28

## 新增系统分类

- `visuo_tactile_world_model`：根据动作生成未来视觉与触觉观测，用于数据增强和策略评估。
- `industrial_skill_capture_stack`：目标机器人手、同源穿戴式采集设备、模型和部署系统组成的工业闭环。
- `dynamic_bimanual_policy`：将另一臂或动态对象作为任务参数、无需固定leader/follower的双臂策略。
- `multi_hand_policy_grounding`：把抽象多手轨迹分配并落地到物理多臂配置轨迹的执行层。
- `tactile_safety_reflex`：独立于任务策略的皮肤触觉撤退、停机和恢复控制。
- `monolithic_soft_hand`：使用单体打印和软体腔室实现手指/掌部运动的低装配复杂度本体。

## 生成视触觉数据字段

所有世界模型生成数据必须保存：

- `rollout_source`: `real | simulation | generated`
- `world_model_name`
- `world_model_checkpoint`
- `generation_round`
- `conditioning_frame_ids`
- `conditioning_action_sequence`
- `generated_visual_streams`
- `generated_tactile_streams`
- `rollout_success_filter`
- `rollout_filter_version`
- `generated_success_prediction`
- `real_imagined_consistency`
- `policy_parent_checkpoint`

生成触觉不得覆盖真实缺失状态；真实、仿真和生成流必须可独立查询。
