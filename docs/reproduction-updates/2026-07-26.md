# 复现路线更新｜2026-07-26

## P0：AnyDexRetarget 冒烟测试

原始链接：https://github.com/qqsq12321/AnyDexRetarget

### 目标

验证同一套人手输入经过不同优化器和目标URDF后，能否稳定映射到多种灵巧手，并建立与当前22路编码器外骨骼的统一接口。

### 最小步骤

1. 安装 Python 3.10、Pinocchio、MuJoCo、NLopt及仓库依赖。
2. 用仓库自带 `right.mp4` 分别运行 Shadow、LEAP、Allegro、Wuji 配置。
3. 比较 `adaptive` 与 `vector`：
   - 平均/最大指尖误差；
   - pinch接触误差；
   - 关节限位违反；
   - 单帧求解时间；
   - 帧间抖动。
4. 将22路编码器数据转换成明确版本的21点骨架或指尖/骨段向量。
5. 运行 `debug_skeleton.py` 和 `calibrate_scaling.py`，保存源骨架、缩放后骨架与目标FK骨架。
6. 选择一个可获得的真机驱动，记录 `command → executed state` 差异。

### 必须保存

- `input_source`
- `source_skeleton_profile`
- `source_hand_scale`
- `segment_scaling_profile`
- `optimizer_type`
- `optimizer_config_hash`
- `target_robot`
- `target_urdf_commit`
- `retarget_latency_ms`
- `retargeted_joint_target`
- `executed_joint_state`
- `joint_limit_violation`
- `pinch_contact_error`

### 难度

- 视频/MediaPipe到MuJoCo：低。
- XR/Noitom到MuJoCo：中。
- 外骨骼/真机闭环：中到高。

## P0：TopoRetarget-Repro 数据与可追溯性审阅

原始链接：https://github.com/Key-Zzs/TopoRetarget-Repro

### 目标

学习其数据、坐标、配置和产物审计方式，并将关键思想迁移到我们自己的离线人手—物体示教转换流程。

### 最小步骤

1. 仅安装核心与可视化依赖，运行CLI和synthetic tests。
2. 阅读：
   - `HOI_DATA_INTERFACE.md`
   - `COORDINATE_CONVENTIONS.md`
   - `LICENSE_AND_DATA_POLICY.md`
   - `ROADMAP.md`
3. 在不下载完整GRAB的条件下检查schema、manifest和hash机制。
4. 若获得GRAB/MANO许可，转换一条短序列至canonical Zarr。
5. 运行Stage 7 warm start、Stage 8 interaction graph及Stage 9 refinement的短片段。
6. 检查每个产物是否能反向追踪到源数据、映射profile、目标URDF、求解器和假设。

### 当前边界

- 仓库是非官方复现。
- Stage 10只报告一段60帧参考运行。
- 未包含论文RL、完整指标或最终结果表复现。
- GPL-3.0代码与外部数据/模型许可证需分开审查。

### 难度

中到高，重点不是算力，而是外部资产、坐标约定和复现边界管理。
