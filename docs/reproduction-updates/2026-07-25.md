# 复现路线更新｜2026-07-25

## 1. FELT 最小复现计划

### 目标

验证“少量同步真实触觉数据训练生成器，再为历史纯视觉/UMI数据补充触觉”的可行性。

### 最小硬件

- 一台机械臂或固定运动平台；
- 双指夹爪或两根可控手指；
- 一台腕部RGB相机；
- 左右各一块压阻/电容触觉阵列；
- 可提供稳定设备时间戳的记录系统。

### 数据采集

1. 同步记录腕部RGB、左右指触觉、夹爪状态、末端位姿与动作。
2. 不在采集时强行重采样；保存各模态原始频率。
3. 通过接触脉冲或已知动作测量RGB—触觉固定时延。
4. 建立左右指独立的触觉图布局和标定元数据。
5. 先采集10–20条简单按压/滑动数据，再扩展到插入、擦拭和套合任务。

### 基线

- vision-only policy；
- real-tactile policy；
- generated-tactile policy；
- copy/mean tactile baseline；
- 无时延校正的生成触觉。

### 指标

- 触觉生成 MAE/SSIM 或物理力误差；
- 接触建立/释放检测F1；
- 滑移和剪切趋势一致性；
- 任务成功率；
- 生成推理延迟；
- 不同相机、光照和对象的OOD性能。

### 必须保存

`tactile_source`、`generator_checkpoint`、`source_rgb_frame_id`、`tactile_latency_correction`、`real_tactile_frame_id`、`sensor_layout_version`、`generation_confidence`。

## 2. URF 控制层复现计划

### 目标

比较“只预测动作”和“同时预测虚拟目标、刚度和阻抗/导纳切换”的接触控制差异。

### 最小实验

- 具有六维F/T或可靠关节力矩估计的机械臂；
- 一个翻转/压紧任务；
- 一个沿轨迹保持压力任务；
- RGB或深度相机；
- 可外部设置阻抗/导纳参数的低层控制器。

### 对照

1. 固定阻抗控制；
2. 固定导纳控制；
3. 动作策略 + 固定低层控制；
4. 策略预测力目标；
5. 策略预测虚拟目标、刚度和切换比例。

### 记录字段

`virtual_target_pose`、`stiffness_matrix`、`damping_matrix`、`impedance_admittance_ratio`、`controller_mode`、`raw_wrench`、`force_growth_rate`、`torque_command`、`safety_clamp_event`。

### 安全要求

- 独立硬件急停；
- 最大力/力矩与速度限制；
- 对策略输出的刚度和虚拟目标做边界检查；
- 初期只使用软物体和低速动作。

## 3. AXIS 数据工程冒烟测试

### 目标

学习其数据许可、统一轨迹格式、轨迹精炼和训练接口，不尝试镜像全量2.36 TB数据。

### 步骤

1. 阅读受控数据条款，记录非商业和禁止再分发限制。
2. 申请数据访问，优先下载最小可用子集。
3. 检查episode是否包含task、embodiment、simulator version、observations、states、actions和success。
4. 对同一轨迹分别保存raw与refined版本。
5. 实现hesitation removal、平滑和重采样的最小复刻。
6. 用小型策略比较原始轨迹与精炼轨迹的训练效果。

### 指标

- 原始/精炼轨迹成功率；
- 动作速度、加速度和jerk；
- 被删除停顿占比；
- 轨迹处理耗时；
- 数据版本可追溯性；
- License合规性。

## 4. BiCompoDiff 数据表示复现

暂不复现完整扩散与MCMC系统，先在现有双臂/仿真任务中建立阶段数据结构：

`pick → transfer → handover → regrasp → place`

每阶段保存：

- 左右手/夹爪6D；
- 抓取候选ID；
- 碰撞、可达性和稳定性分数；
- 阶段进入/退出条件；
- handover接触重叠区间；
- 重抓原因与执行结果。

后续若扩展到五指手，再加入每指接触、抓力和滑移。

## 5. Scale Up Strategically 数据审计

对现有任务表做低成本离线审计：

1. 从语言指令中提取颜色、对象、空间关系、动作词、尺寸、材质和接触类型。
2. 统计每个因素和因素组合的episode数、成功率和失败率。
3. 识别模型成功率低但数据量少的因素。
4. 给下一轮采集分配优先级。
5. 记录每新增一条示教带来的边际收益。

建议字段：

`instruction_factors`、`factor_coverage_count`、`factor_success_rate`、`factor_mastery_score`、`collection_priority`、`marginal_gain_per_demo`。

## 6. G1 + BrainCo DDS数字孪生冒烟测试

### 目标

验证仿真和真机接口同构度，建立人形身体、双手、第一视角与日志系统的统一消息注册表。

### 步骤

1. 安装MuJoCo与`unitree_sdk2_python`。
2. 运行`G1_BrainCo_hands_Digital_Twin_Mujoco`。
3. 监听`rt/lowstate`和左右`rt/brainco/{side}/state`。
4. 运行仓库的全身+双手插值示例，记录topic、消息结构、关节顺序、单位和频率。
5. 切换头部第一视角相机，验证图像和机器人状态时间戳。
6. 建立同一控制程序的`sim`与`real`配置文件，仅允许修改DDS domain、网卡和设备地址。
7. 显式记录仿真缺失通道：手部电流、`tau_est`、触觉、tip关节接触和高层`arm_sdk`。

### 指标

- topic parity；
- message schema parity；
- joint order parity；
- unit parity；
- sim/real配置差异行数；
- 控制与状态频率；
- DDS端到端延迟；
- 缺失物理通道数量。

### 判定

若动作程序可以在不修改控制逻辑的情况下切换sim/real，且所有缺失通道均有显式mask，则可作为采购前集成测试床；否则仅作为可视化模型。

## 7. ISyHand掌部自由度对照实验

### 目标

量化可动掌部对手内重定向、可达空间和策略学习效率的影响。

### 步骤

1. 下载ISyHand、ISyHand flat、Allegro和LEAP的官方URDF/mesh。
2. 按仓库固定IsaacGymEnvs commit配置环境。
3. 先运行四个预训练checkpoint，确认评测脚本一致。
4. 使用相同立方体初始/目标位置评估100回合。
5. 记录成功率、掉落率、关节限位、接触数和策略动作幅度。
6. 如算力允许，以相同seed和迭代预算重新训练。
7. 将现有22路外骨骼动作分别retarget到articulated palm与flat palm模型，比较指尖误差和任务表现。

### 必须保存

`palm_dof`、`palm_articulation_type`、`palm_state`、`hand_asset_source`、`asset_commit`、`upstream_license`、`checkpoint_hash`。

## 8. DEED数据工程复现实验

### 目标

不复现完整GR00T训练，先验证频率对齐、失败尾段裁剪、恢复动作保留和经验回流质量门控的效果。

### 最小数据

使用现有机器人或公开episode构建：

- 50–100条人工示教；
- 20–50条自主rollout；
- 成功、失败、恢复和人工纠错标签；
- 至少两路相机和机器人状态。

### 对照流程

1. naive SFT：原始数据直接训练；
2. frequency-aligned：统一相机、落盘和动作时间轴；
3. curated：删除无效失败尾段，保留具有纠错价值的恢复片段；
4. first refinement：加入经过质量筛选的自主经验；
5. second refinement：继续加入经验，观察是否发生分布漂移。

### 必须保存

- `camera_rate_hz`
- `record_rate_hz`
- `policy_rate_hz`
- `raw_episode_id`
- `curated_episode_id`
- `trim_reason`
- `autonomous_rollout`
- `human_correction`
- `advantage_label`
- `ood_score`
- `refinement_round`
- `policy_checkpoint_parent`
- `data_mix_ratio`

### 质量门控

- 每轮训练前后固定评测集；
- 限制自主数据比例；
- 拒绝高OOD、低价值或重复轨迹；
- 性能退化时自动回滚checkpoint和数据快照；
- 不把Dex-3二值开/闭动作视为完整灵巧手关节监督。
