# 复现路线更新｜2026-07-28

## P0：ViTacWorld代码发布后复现

- **项目页：** https://vitacworld.github.io/
- **当前状态：** 论文和结果已公开，GitHub Coming Soon。
- **最小目标：** 不先训练完整世界模型，优先核验数据schema、动作定义、双视角与触觉同步方式、生成rollout筛选器。
- **完整复现路径：**
  1. 准备主视角RGB、腕部RGB、双指触觉、相对EEF动作和夹爪状态。
  2. 复现真实/仿真预训练混合数据格式。
  3. 训练或加载动作条件视触觉DiT。
  4. 对固定首帧和动作序列生成三路未来观测。
  5. 将生成轨迹标记为`generated`，通过成功判定器筛选。
  6. 对同一策略比较expert-only、round-1和round-2增强。
- **指标：** 视觉一致性、触觉接触时间误差、触觉强度/形变误差、生成成功率precision/recall、真实策略提升、real-imagined rank correlation。
- **难度：** 高。

## P0：DynaMAC / DynaBench smoke test

- **开源入口：** https://dynamac.cs.uni-freiburg.de/
- **目标：** 验证仅用静态示教能否在动态目标和双臂交接中零样本运行。
- **步骤：**
  1. 安装RLBench与DynaBench。
  2. 运行一个静态单臂任务基线。
  3. 开启移动对象并记录标准多流策略失效。
  4. 启用运动学链接检测与动态frame过滤。
  5. 运行双臂handover，检查另一臂frame是否动态成为主参考。
  6. 对比固定leader/follower、monolithic和DynaMAC。
- **必须保存：** `skill_boundary`、`task_parameter_frame`、`kinematic_link_state`、`link_threshold`、`virtual_eef_frame`、`selected_streams`、`emergent_leader_role`。
- **难度：** 中。

## P1：多手策略grounding规划器

- **项目页：** https://omcbsa.github.io/
- **目标：** 将两条抽象手轨迹安全映射到两条冗余机械臂。
- **步骤：**
  1. 使用双臂URDF和简单无障碍轨迹验证arm assignment。
  2. 增加臂间碰撞，检查Conflict-Based Search。
  3. 启用Jacobian null-space避碰。
  4. 注入不可行轨迹，验证失败报告而非静默输出。
  5. 后续将BiCompoDiff/DynaMAC输出接入规划器。
- **指标：** assignment正确率、规划时间、轨迹误差、碰撞率、关节限位违反率、不可行检测率。
- **难度：** 中到高。

## P1：OSOR单元机械复现

- **论文：** https://arxiv.org/abs/2607.22320
- **最小硬件：** 单个AOB-S指单元或AOB-D掌单元、SLS TPU打印、压力源、压力传感器、角度测量和力计。
- **实验：**
  - 压力—弯曲角曲线；
  - 压力—输出力曲线；
  - 加载/卸载迟滞；
  - 1–5 Hz动态响应；
  - 1000/10000周期泄漏和疲劳；
  - 不同打印方向和壁厚的气密性。
- **难度：** 中到高；整手复现暂不建议。

## P2：触觉安全反射原型

- **论文：** https://arxiv.org/abs/2607.22249
- **最小实现：** 在现有触觉传感器或腕部F/T上构造独立安全节点，比较统一关节撤退和沿接触法向Cartesian撤退。
- **关键原则：** 安全反射必须优先于任务策略、具有硬限幅、可审计，并在撤退后进入明确恢复状态。
- **保存字段：** `reflex_type`、`pain_gain`、`contact_pad_id`、`contact_normal`、`task_interrupt_timestamp`、`withdrawal_trajectory`、`return_pose`、`reflex_outcome`。
- **难度：** 中。
