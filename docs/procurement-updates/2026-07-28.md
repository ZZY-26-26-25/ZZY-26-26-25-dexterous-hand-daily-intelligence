# 采购与供应商跟踪更新｜2026-07-28

## Tacta Systems：高优先级询价，暂不直接采购

- **产品：** [TactaBot / Tacta Hand / Tacta Glove](https://www.tactasystems.com/)
- **状态：** 2026-07-27首次公开，计划2027年初进入电子、AI基础设施与汽车制造部署。
- **已公开规格：** Tacta Hand为15个独立驱动关节，Fluidic Tendon驱动；触觉动态范围250–700,000 Pa、400 Hz、温度分辨率0.1°C；Tacta Glove记录力、动作、视频和温度。
- **未公开：** 价格、重量、负载、运动范围、手套DoF、传感器数量和布局、腕部6D、SDK、ROS2、数据格式、原始触觉访问、数据和模型所有权。
- **判断：** 技术闭环价值高，但开放度未知。应先索取技术包、样例数据和合同条款，再决定是否进入采购候选。

## 询价新增必问字段

### 同源手套—机器人手闭环

- 人手与机器人手的关节/传感器是否一一对应？
- `human_robot_sensor_correspondence`是否公开且有版本号？
- 手套与机器人手是否使用完全相同的传感器、采样电路和标定模型？
- 手套动作、触觉、温度、视频和机器人执行数据是否共享设备时钟？
- 是否允许导出逐传感器400 Hz原始数据，而非只提供特征或模型输出？
- 数据所有权、派生模型权利、再训练和发表权限如何约定？

### 工业可靠性与维护

- “数百万周期”的测试工况、负载、速度和失效定义是什么？
- Fluidic Tendon的工作介质、压力、泄漏检测、维护周期和耗材是什么？
- 单个关节/传感器更换时间和现场维护工具？
- 维护事件能否写入日志并绑定硬件序列号？
- 触觉传感器在温度、油污、粉尘和长时间加载下的漂移？

## OSOR软体手：结构复现优先于采购

- **论文：** https://arxiv.org/abs/2607.22320
- 当前没有标准产品或开放采购入口。
- 适合先复现单个AOB/ADC执行单元，测量SLS TPU气密性、弯曲角、输出力、迟滞和循环寿命。
- 不应将其与全驱动、高可观测灵巧手直接比较；其优势是低装配复杂度、被动安全和掌部形变。

## 新的暂停采购条件

- 厂商声称采集“完整物理技能”，但不能导出力、动作、温度和视频原始流；
- 采集手套与目标手宣称同源，却不提供映射、布局和标定版本；
- 工业寿命只给总周期数，不说明工况、故障率和维护事件；
- 触觉动态范围很大，但不提供噪声、分辨率、迟滞、漂移和过载恢复；
- 生成式世界模型数据被作为真实数据交付，却没有来源和checkpoint标记。
