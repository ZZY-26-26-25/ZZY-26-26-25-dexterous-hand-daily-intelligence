# 采购与供应商跟踪更新｜2026-07-25

## 今日结论

过去 24–72 小时没有发现具有完整新规格、标准报价或正式 SDK 大版本的商业灵巧手发布。今日新增更适合用于调整采购技术要求，而不是立即下单。

## 新增采购要求

### 1. 触觉数据平台：支持少量真实触觉标定与大规模视觉数据补全

FELT 表明，大量历史 UMI/RGB 数据可以通过少量同步真实触觉数据训练生成模型，再补充逐指触觉观测。采购触觉执行手或夹爪时新增要求：

- 必须允许导出原始逐指/taxel触觉，而非只输出接触标签；
- 必须公开触觉布局、单位、采样率、延迟、校准和零点状态；
- RGB、触觉和机器人状态必须具有设备时间戳或可测时延；
- 允许将少量高质量真实触觉数据用于独立模型训练，不得限制本地数据导出；
- 采购合同应明确原始触觉数据和派生模型的研究使用权。

### 2. 执行端控制：不仅要有位置控制，还要开放阻抗/力矩接口

URF 说明，接触任务性能依赖虚拟目标、刚度和阻抗/导纳模式。采购机械臂或灵巧手时新增询问：

- 是否支持 torque、impedance、admittance 或 hybrid control；
- 是否允许在线设置刚度/阻尼和最大力限制；
- 是否能读取低层 torque command、控制器模式、F/T原始值和力增长率；
- 低层安全控制频率、网络延迟和急停行为；
- 厂商控制器能否被外部策略以稳定固定周期调用。

仅提供目标角度、但不能获得低层力学状态的产品，不适合作为高价值接触数据平台。

### 3. 数据许可：受控数据不能镜像到公共仓库

AXIS Franka Dataset 为受控访问，当前条款限定非商业学术与教育用途，并禁止再分发、公开镜像和商业训练。采购或接入外部数据服务时必须记录：

- `license_scope`
- `commercial_use_allowed`
- `redistribution_allowed`
- `access_request_required`
- `dataset_version`
- `download_date`

公共 GitHub 仓库只能保存元数据、原始链接和使用条款摘要，不能上传受控数据本体。

### 4. 数字孪生必须与真机接口同构

新发布的 G1 + BrainCo MuJoCo 数字孪生说明，采购前可以用仿真检查真实 DDS topic、消息定义和控制程序，但仅有外观相同的 URDF 远远不够。新增字段：

- `sim_model_available`
- `sim_transport_parity`
- `topic_parity`
- `message_schema_parity`
- `joint_order_parity`
- `unit_parity`
- `control_mode_parity`
- `missing_physics_channels`

必须询问：

1. 仿真和真机是否使用相同 topic、消息结构、关节顺序和物理单位；
2. 控制程序能否只更改网络/设备配置而不重写动作逻辑；
3. 是否模拟电流、力矩、摩擦、腱耦合、指尖接触和触觉；
4. 仿真文件、参考模型和 mesh 的许可证是否允许研究发布。

### 5. Revo2、Revo3及定制版本不可混用

本次社区数字孪生基于 Revo2 型 6 主动 / 11 总 DoF 手，不能据此推断 Revo3 触觉版的关节、SDK、触觉或控制能力。询价时必须绑定：

- 具体 SKU 与左右手版本；
- 官方 URDF/MJCF/mesh commit；
- hand service topic 与消息版本；
- 逐电机电流、`tau_est`、温度、故障和原始触觉接口；
- SDK、固件和数字孪生的版本对应关系。

### 6. 人形VLA平台必须支持数据回流审计

DEED表明，第一轮自主经验可提升性能，但第二轮可能因分布漂移显著退化。采购或建设数据平台时新增要求：

- 公开相机采样、落盘、控制与推理频率；
- 保存原始episode和清洗episode的父子关系；
- 保存失败尾段、恢复动作、人工纠错和自主rollout；
- 支持checkpoint、数据轮次和性能的可追溯关系；
- 提供OOD、优势标签或质量评分；
- 允许回滚旧checkpoint与旧数据快照。

## 暂不采购条件补充

出现以下情况应暂停采购：

- 触觉数据只有厂商可视化界面，不能读取原始值；
- RGB与触觉没有设备时间戳，也无法测量稳定延迟；
- 只支持位置目标，无法设置力、阻抗或安全接触限制；
- 数据合同禁止本地训练、导出或生成派生触觉模型；
- 对外宣称开放数据，但实际许可禁止当前研究或公开复现用途；
- 仿真只提供外观模型，不能复用真机topic、消息与单位；
- 同一产品代际或左右手的关节/耦合定义不一致；
- 厂商无法说明动作、相机、记录和推理频率；
- 自主数据回流没有质量门控、checkpoint追踪和回滚机制。
