# 采购与供应商更新｜2026-07-27

## 1. 今日结论

今日最明确的采购线索是 **Trossen TRumi**，最明确的DIY线索是 **HandUMI**。两者都属于机器人无本体的平行夹爪示教采集，不应与多指数据手套或机械同构外骨骼直接混为一类。

## 2. Trossen TRumi

- 官网：https://www.trossenrobotics.com/trumi
- 标准价格：双设备含2套GoPro HERO13和Ultra Wide Lens Mod为 **2,195.99美元**；不含GoPro为 **949.95美元**。
- 2026-07-27观察到的促销价：不含GoPro的双设备最低 **854.96美元**，官方社媒称促销截至2026-08-12；价格具有时效性。
- 输出：末端6D、夹爪开度、图像；MCAP另含原始IMU，支持Zarr。
- 适用：多操作者、多地点、单/双手UMI示教；不适合直接生成五指关节和逐指触觉数据。
- 询价必须确认：
  - 整机与单只重量；
  - 机械寿命、回差和保修；
  - 数据流水线仓库、版本固定与离线许可；
  - GoPro序列号绑定、相机替换和标定流程；
  - SLAM失败率、episode丢弃条件和技术支持；
  - 国内运费、税费和备件；
  - 是否提供机器人specific retarget/validation服务。

## 3. HandUMI DIY

- 硬件：https://github.com/robonet-ai/handumi-hw
- 软件：https://github.com/robonet-ai/handumi-sw
- 公开BOM：约 **110美元/只、221美元/双手**，不含PICO 4 Ultra或Meta Quest 3。
- 开放程度：STL、BOM、装配、采集、标定、验证、回放和retarget均公开，原创硬件/软件为Apache-2.0。
- 适用：建立最低成本的机器人无关双手平行夹爪数据基线；适合USB插入、抓放、双手配合等。
- 不适用：完整手指姿态、逐指触觉、手内操作和高保真抓力研究。
- DIY前确认：
  - 本地Feetech伺服和鱼眼UVC相机替代型号；
  - PICO/Quest应用兼容性；
  - 操作者手型托架是否需要重建；
  - 双手同步、相机帧率和XR坐标漂移；
  - tip与目标夹爪尺寸、开度和TCP的一致性。

## 4. 采购分类新增字段

UMI/无本体设备新增以下采购字段：

```text
interface_form                 # handheld / wearable / mechanically-isomorphic
end_effector_class             # parallel_jaw / multi_finger / tool
measured_action_rank           # 1D aperture / 6D+aperture / full hand
operator_contact_feedback      # direct natural / passive mechanical / active haptic / none
electronic_tactile_capture     # yes/no
pose_source                    # XR / VIO / SLAM / mocap
mapping_required               # yes/no
robot_specific_validation      # required/optional
raw_format                     # MP4/MCAP/Zarr/LeRobot
hardware_price_usd
required_tracking_hardware
maintenance_model              # DIY / supported product
```

## 5. 暂不替代当前外骨骼路线

HandUMI与TRumi均不应替代22路编码器外骨骼。它们更适合：

1. 快速扩大平行夹爪任务、场景和物体覆盖；
2. 建立低成本无本体采集基线；
3. 测试MCAP、retarget和数据质量流程；
4. 为后续多指外骨骼数据提供对照组。

对于灵巧手研究，采购/DIY优先级应理解为：

- **HandUMI：P0软件与单手DIY复现**；
- **TRumi：P1询价和数据样例索取**；
- **完整多指手套/机械同构外骨骼：继续作为主线**。
