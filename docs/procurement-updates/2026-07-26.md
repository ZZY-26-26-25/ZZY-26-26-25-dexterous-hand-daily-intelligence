# 采购与供应商更新｜2026-07-26

## 1. BrainCo RevoHand SDK v2.0.3

- 官方示例仓库于 2026-07-23 将 `bc-stark-sdk` 从 2.0.2 更新至 2.0.3。
- 当前公开 `CHANGELOG.md` 未列出 v2.0.3 的功能变化，因此不能将其描述为新触觉功能或新硬件支持。
- 核心 SDK 采用专有二进制许可；GitHub 中的示例、安装脚本和接口展示不等于底层库开源。
- Revo1/Revo2 支持的通信路径不同，采购时必须绑定：硬件型号、通信协议、固件、SDK版本和触觉版本。

## 2. AnyDexRetarget 对硬件采购的影响

AnyDexRetarget已经支持13种目标手模型，但仅部分目标手提供真机驱动。采购目标手时不能只依据“存在URDF配置”，还应确认：

- 真机控制驱动是否已实现并维护；
- 是否支持执行状态、电流、触觉和错误码回读；
- 目标URDF、joint mapping和真机固件是否一一对应；
- 是否允许外部实时发送完整关节目标；
- 是否有可靠的左右手、双手同步和设备时钟；
- 社区驱动是否获得厂商SDK许可并能长期使用。

原始链接：https://github.com/qqsq12321/AnyDexRetarget

## 3. Gaia Hand20 采购状态

AnyDexRetarget新增了Gaia Hand20的官方HandSDK驱动示例，但这只是社区集成信号，不代表Gaia Hand20的价格、供货、触觉或科研接口已核验。

采购前需继续确认：

- 关节数、主动/耦合/被动DoF定义；
- HandSDK v1.1.1许可和升级策略；
- 关节位置、速度、电流、温度、故障与触觉接口；
- Linux x86_64/aarch64、ROS2、CAN/CAN-FD支持；
- 左右手价格、交期、备件和售后。

## 4. 今日采购结论

- **无立即采购建议。** 本轮是软件接口和版本管理更新，而非经过独立验证的新硬件发布。
- BrainCo继续保留高密度触觉商业对照候选，但必须先获得2.0.3完整变更说明和真实日志样例。
- AnyDexRetarget适合采购前验证目标手的运动学可接入性，不能替代真实力学、触觉和可靠性测试。
